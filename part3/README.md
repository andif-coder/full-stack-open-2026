# Phonebook Full Stack Application

This is a full-stack phonebook application built as part of the [Full Stack Open](https://fullstackopen.com/) course (Part 3).

## Live Demo

The application is deployed on Render:
* **Production App**: [https://backend-lw5i.onrender.com/](https://backend-lw5i.onrender.com/)
* **API Endpoint**: [https://backend-lw5i.onrender.com/api/persons](https://backend-lw5i.onrender.com/api/persons)
* **Info Endpoint**: [https://backend-lw5i.onrender.com/info](https://backend-lw5i.onrender.com/info)

---

## Features

- **View Persons**: Displays a list of contacts with their names and phone numbers.
- **Add Person**: Allows users to add new contacts to the phonebook.
- **Delete Person**: Delete a contact entry from the phonebook.
- **Single Page Application**: React frontend served directly by the Express backend as static production assets.

---

## Tech Stack

### Frontend
- **React** (Vite)
- **Axios** for API communication

### Backend
- **Node.js**
- **Express** for RESTful API routing and static middleware
- **Morgan** for HTTP request logging
